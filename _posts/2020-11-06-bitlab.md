[Bitlab](https://www.hackthebox.eu/home/machines/profile/207) je stroj z Hack The Box. Klíčová část útoku je webová enumerace a praktické zneužití nalezené slabiny.

### Vyhledání otevřených portů
Nejdřív mapuji služby, které jsou dostupné zvenku.
`nmap -p 1-65535 -T4 -A -sC -v $IP`
```
PORT   STATE SERVICE VERSION
```

### Vyhledání otevřených portů (2)

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`cat clave/user.txt`
```
__CENSORED__
```

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`cat /root/root.txt`
```
__CENSORED__
```
